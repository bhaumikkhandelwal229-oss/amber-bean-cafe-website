Amber & Bean — Jaipur Café Website

A modern, responsive café website built with HTML, CSS, JavaScript, and Tailwind CSS.
The project is designed as a clean portfolio-ready frontend website for a Jaipur-based café concept.

🌐 Live Preview

You can deploy this project easily using GitHub Pages, Netlify, or Vercel.

✨ Features

Responsive café landing page

Clean and modern coffee-inspired UI

Sticky navigation bar

Home, Menu, Gallery, and Contact sections

Single-page navigation using JavaScript

Active navigation state

Hero section with custom CSS coffee artwork

Café statistics and feature cards

Menu cards with prices

Business hours section

Responsive gallery layout

Contact form with basic client-side submission interaction

Location/contact information section

Mobile responsive design

Tailwind CSS via CDN

Custom CSS animations and hover effects

🛠️ Technologies Used

HTML5 — Page structure and semantic content

CSS3 — Custom styling, gradients, responsive behavior, and animations

JavaScript — Page navigation and contact form interaction

Tailwind CSS — Utility-first responsive styling

🚀 How to Run Locally

Clone the repository:

git clone https://github.com/YOUR-USERNAME/amber-bean-cafe-website.git

Open the project folder:

cd amber-bean-cafe-website

Open index.html in your browser.

No build tools or package installation are required.

📌 Project Highlights

Home

Introduces Amber & Bean with a Jaipur-focused café concept, hero section, café statistics, features, testimonials, and a call-to-action.

Menu

Includes drinks, breakfast, and all-day food items with prices.

Gallery

Provides a responsive gallery-style section using CSS-generated visual cards.

Contact

Includes a contact form, café address, phone number, email, business information, and a map placeholder.

🎨 Design

The design uses a warm café-inspired color palette with cream, brown, and orange tones. The layout focuses on simplicity, readability, spacing, rounded cards, and responsive behavior.

⚠️ Notes

The contact form currently uses JavaScript to display a confirmation alert; it does not send data to a backend.

The map area is currently a placeholder and can be replaced with a real Google Maps embed.

The café contact details and menu data are demo content and can be replaced with real business information.

Tailwind CSS is loaded from the CDN, so an internet connection is required for Tailwind utility classes to load.
